This directory contains context for AI.
It is the place to save data for AI and it is the place the AI itself saves data for context.

Files:

- `ran-regev-portfolio-chat-notes.md` — the original ChatGPT reconstruction of
  the portfolio discussion. Left untouched.
- `decisions.md` — agreed decisions, deferred items, and the working agreement.
- `site-structure.md` — the tree, card inventory, data model, and build
  pipeline.
- `asset-inventory.md` — what exists, what is missing, and where each asset is
  used.
- `design-brief.md` — the chosen yin-yang field board, its single composite
  background, palette, type, and the anchor studies.

When a decision changes, update `decisions.md`; when the structure changes,
update `site-structure.md`. Keep this directory as the source of context for
new sessions.
