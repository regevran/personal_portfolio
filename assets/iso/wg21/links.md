# P3817 - Structured Binding Assignment
Link: wg21.link/p3817
Content: the paper seeks to add a new ability to C++ by providing a way to assign into exsiting variables within structured binding declaration.
e.g.
```cpp
std::string scientific_name;
auto [using scientific_name, ringer_name] = get_identity();
```
